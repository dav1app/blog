{%- comment -%} Renders a post date as YYYY-MM-DD. Kept as an include so the site has a single place to change date formatting. No locale workaround is needed here: Liquid's `date` filter only lacks locale support for month *names* (%b/%B), and a numeric ISO date sidesteps that. Usage: {% include post-date.html date=post.date %} {%- endcomment -%} {{- include.date | date: "%Y-%m-%d" -}}
